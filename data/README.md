# Data Directory

This directory contains synthetic marketplace data generated by the Marketplace Trust Engine.

## Structure

- `raw/` - Raw generated data in Parquet format (one file per entity)
- `processed/` - Feature-engineered data ready for model training

## Generating Data

```bash
make generate-data
```

Or with custom parameters:

```bash
poetry run python scripts/generate_data.py --seed 42 --n-sellers 1000
```

## Files

| File | Description |
|------|-------------|
| `raw/users.parquet` | User accounts |
| `raw/sellers.parquet` | Seller profiles with fraud labels |
| `raw/listings.parquet` | Product listings |
| `raw/transactions.parquet` | Purchase transactions |
| `raw/reviews.parquet` | Buyer reviews |
| `raw/devices.parquet` | Device records |
| `raw/events.parquet` | User behavioral events |
| `raw/metadata.json` | Generation metadata and statistics |

## Important Notes

**All data is synthetic.** It is generated by a probabilistic simulator and does not represent real users, sellers, or transactions.

Fraud labels are assigned based on behavioral scenarios simulated during data generation, not by post-hoc label assignment. This design choice prevents target leakage.
